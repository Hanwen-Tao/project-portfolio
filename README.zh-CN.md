## 贯穿的主线

三条关注点贯穿所有项目，也是我希望导师据以判断我的地方。

**一 · 把结论变成可度量的。** 每个项目最终都有由我自己写的评测工具产出的数字，而不是"看起来不错"：18 轮迭代每轮记录 F1（ARTIFEX）、精度/FLOPs/参数量/延迟四维对比（剪枝）、含极限难例的 12 算法基准（匹配）、棋型判定回归检查（五子棋），以及附校验值冻结的原始产出，报告里每个检索数字都能重新算出来（失物检索）。

**二 · 把"判定"与"计算"分开。** 反复出现的架构动作是：在确定性内核与概率性/外部组件之间放一层有界接口——ARTIFEX 中规则候选分析与 LLM 生成分离、临床平台中后端会话状态与模型服务分离、棋类引擎中战术层与搜索核心分离。

**三 · 对数字的含义保持诚实。** 合成数据结果与真实数据结果分别标注，即使真实数据上的表现差很多也如实报告——见 [ARTIFEX 评测一节](docs/zh-CN/01-artifex.md#七评测与数字的边界)：规则线在合成数据上 F1 0.964，在 81 条真实 JD 上精确率仅 0.158，两者都记录在案。

## 研究兴趣

- **大语言模型系统与智能体** —— 编排、观测与成本归因、评测体系、回归门禁、工具调用安全。
- **文本与图数据上的机器学习** —— 信息抽取、技能与能力本体、新颖性检测、匹配与排序。
- **高效深度学习与边缘智能** —— 模型压缩（结构化剪枝、量化）、端侧推理、效率与精度的权衡。
